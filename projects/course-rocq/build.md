Build suitable slides following the target .html and .v files. 

## Requirements

1. The outline of the ppt follows the sections of head `h1`, `h2`, ... in the .html file: 
    - sections of the ppt follows the sections of `h1`;
    - subsections of the ppt follows the sections of `h2`; 
    - make an outline slide at the beginning of the ppt;
    - each head of the ppt is titled as ``section`` or ``section:subsection`` (if there is a subsection). 

2. Adjust the content to the slides properly:
    - Each line of text, each paragraph should be made as an item (with a bullet-like symbol at the beginning)
    - Code region use a darker color to distinguish from the rest of the text, adjust the size of the code region properly. 
    - For the text of each item, optimize the content: make better summarizing, using shorter sentences or key words. Try no more than one sentence of an item. If there are more than one sentences, make them multi-lines or use sub-items.
