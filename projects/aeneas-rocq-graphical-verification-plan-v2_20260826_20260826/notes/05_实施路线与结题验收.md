实施工作分为六个有完成标志的阶段。第一阶段确定边界，形成目标函数、unsafe 调用、外部依赖和可信假设清单；第二阶段固定工具版本，打通 Charon 提取与 Aeneas Coq 输出，得到可加载的 LLBC 和 Rocq 文件；第三阶段建立页面状态、权限关系和生命周期规约，形成抽象状态与安全不变式；第四阶段证明访问、回收和重新分配函数；第五阶段从这些函数证明中归纳典型安全属性；第六阶段整理源码、模型、证明脚本、复现说明和验证报告。

结题指标可以压缩成一、三、二、一：不少于一个机密计算 Rust 核心安全模型，不少于三项关键操作，不少于两类典型安全属性，以及一套验证案例和分析报告。同时还要实际完成 Rust 安全关键代码到 Rocq 函数式模型的转换。三项操作优先选择访问权限检查、页面回收和页面重新分配，两类属性优先选择访问隔离与页面重分配防泄露。

最终价值不是宣称整个系统已经被彻底验证，而是建立一条可复现、可解释、可扩展的 Rust 到 Rocq 实现级验证路线。只要边界、假设、模型、操作证明和复现材料能够闭合，这个研究项目就具备清晰而务实的验收依据。
